# pwdgen — Генератор паролей с CSPRNG на Java 17

Криптографически стойкий генератор паролей без внешних зависимостей.

## Предупреждение
Я не разработчик и никогда им не был. 
Как бывший SAST инженер, и человек из сферы информационной безопасности я писал программу с фокусом на безопасность. 
Программа разработана с помощью локальной llm, omnicoder-9b-q5_k_m, на стеке llama.cpp + OpenCode.
Программа прошла все правила по вектору безопасности SonarQube для С++.


## Принципы разработки
- **Конфиденциальность**: Никакого логирования, никакой истории. Пароль генерируется и исчезает.
- **Целостность**: Только криптографически стойкая случайность. Никаких псевдослучайных генераторов.
- **Доступность**: Один запуск — один пароль.

## Возможности
- **Только CSPRNG** — используется `SecureRandom` из Java, а не псевдослучайные генераторы
- **Платформозависимые источники энтропии:**
  - Windows: `SecureRandom` с `RandomProvider`
  - macOS: `SecureRandom` с `SecureRandom`
  - Linux: `SecureRandom` с `SecureRandom`
- **Полный контроль набора символов** с помощью `-nl`, `-nu`, `-nd`, `-ns`

### Проверяемые платформы
Windows; код для macOS и Linux добавлен, но сборка и функциональность не были проверены.
Всё равно, кто знает — попробуйте и сообщите об ошибках.

### Распространённые сценарии

| Флаг | Описание | Значение по умолчанию |
|------|----------|----------------------|
| `-h, --help` | Показать это сообщение помощи | — |
| `-l N` | Длина пароля (1 ≤ N ≤ 256) | 16 |
| `-c M` | Количество паролей (1 ≤ M ≤ 10000) | 1 |
| `-nl` | Исключить строчные буквы | включено |
| `-nu` | Исключить заглавные буквы | включено |
| `-nd` | Исключить цифры | включено |
| `-ns` | Исключить символы | включено |

### Быстрый старт

```bash
# Пароль длиной 16 символов со всеми типами символов
java -jar target/pwdgen-1.0.0.jar

# Показать помощь
java -jar target/pwdgen-1.0.0.jar -h

# Только буквы и символы (без цифр)
java -jar target/pwdgen-1.0.0.jar -l 24 -nd

# Только заглавные буквы и символы
java -jar target/pwdgen-1.0.0.jar -l 20 -nl -nd -ns

# Только строчные буквы (без других типов)
java -jar target/pwdgen-1.0.0.jar -l 32 -nu -nd -ns

# Все типы кроме символов (буквы + цифры)
java -jar target/pwdgen-1.0.0.jar -l 24 -ns

# Сгенерировать 5 паролей
java -jar target/pwdgen-1.0.0.jar -c 5

# Сгенерировать пароль длиной 24 символа
java -jar target/pwdgen-1.0.0.jar -l 24
```
